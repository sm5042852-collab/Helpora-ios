# HELPORA Feature Catalog

## Account
Profile, languages, city, bio, avatar, verification, trust score, activity, privacy, account deletion, recovery, sessions.

## Help
Create request, categories, search, filters, urgency, status, response windows, expiry, resolution, history, saved requests, matching.

## Meeting
Request to connect, pre-meeting chat, acceptance, mutual confirmation, reminders, safety check, meeting history, cancellation, feedback.

## Messaging
Inbox, request chat, read state, typing state, media sharing, translation assistance, mute, block, report, moderation.

## Community
Organizations, events, volunteering, groups, local discovery, announcements, guides, resources, education, jobs, housing.

## Safety
Trust Center, reporting, blocking, privacy controls, verification, safety tips, emergency guidance, trusted contact, abuse prevention.

## Accessibility
Language preference, large text preference, motion preference, screen-reader support target, contrast target, inclusive copy.

## Growth
Notifications, referrals, HP points, achievements, milestones, activity summaries, feedback, surveys.

## Production
Authentication, backend, cloud data, authorization, push notifications, moderation, analytics, automated tests, CI, TestFlight.

The catalog is intentionally expandable. Features count only when implemented and testable.
