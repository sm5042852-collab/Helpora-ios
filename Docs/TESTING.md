# HELPORA iOS Testing

## Current status
The repository now contains a working SwiftUI app structure and onboarding flow.

## Before TestFlight
TestFlight requires an Xcode build and an active Apple Developer Program membership.

## Free local testing
On a Mac:
1. Open the project source in Xcode.
2. Create/open an iOS App target named HELPORA.
3. Add the Swift files from this repository to the target.
4. Choose an iPhone Simulator.
5. Press Run.

## Current test flow
Onboarding → Start HELPORA → Home → Ask for help → Profile.
